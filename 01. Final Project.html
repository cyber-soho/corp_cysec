Mission Briefing & Context

This section provides the foundational context for the project. It outlines the fictional client you are protecting, the stakes involved, and how your efforts across the four stages will be evaluated. Understanding the client's profile is critical, as your security recommendations must fit a mid-size manufacturer's resources, not a Fortune 500 budget.

🏭 Client: NordForge Industries Inc.

  • Profile: Quebec precision-forging manufacturer.
  • Scale: ~180 employees across 3 sites (Montréal HQ, Trois-Rivières plant, Boston R&D).
  • Incident: Recently hit by a phishing incident. Confidential IP at stake.
  • Compliance: Subject to PIPEDA, Quebec Law 25, and Bill C-26.

Key Takeaway

This is not a lecture-style exam. It is a full security lifecycle compressed into four weeks: Build → Harden → Attack → Respond. Siloed answers will lose marks.

Harden & Secure

Due: Thu 11 Jun | Weight: 7%

Focus: Cyber Defence, Compliance

🧱 Firewall Design

  • ✓ Deny by default, allow by exception.
  • ✓ Specific rules before general rules.
  • ✗ No "any-any" rules permitted.
  • ✓ Inter-VLAN routing only at firewall.

🐧 Host Hardening

  • ✓ Linux: SSH key-only, UFW active, auditd, pwquality.
  • ✓ Windows: Disable SMBv1, block NTLMv1, max UAC.
  • ✓ PowerShell logging & AppLocker on.

🔑 AD Security

  • ✓ Tier-0/1/2 admin model.
  • ✓ LAPS implemented.
  • ✓ Protected Users group for DA.
  • ✓ Rotate krbtgt annually.
Vulnerability Management Flow: Scan → Triage (CVSS v3.1/v4) → Assign → Remediate → Verify
